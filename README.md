
# Gelir Gider App

A personal income-expense tracking app built with Flutter.

## Features

- Track income and expense transactions
- Category-based organization
- Dashboard summary overview
- Sign in with Google

## Tech Stack

- Flutter
- GetX (state management)
- Dio (networking)
- Google Sign-In
- Shared Preferences

## Getting Started

```bash
flutter pub get
flutter run
```
